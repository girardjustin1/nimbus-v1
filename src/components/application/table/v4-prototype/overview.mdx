## Current use and gaps

- **V4 currently has light headers.** Manage campaigns has a transparent header over a white surface. The other six implementations use the light secondary surface. The charcoal reference treatment has not been applied to these tables.
- **These are seven native HTML implementations.** They do not use the shared React Aria `Table` compound component. The selected-items pattern is an exact shared component across Apps, Device Language, Keywords and Creative, and already has a Campaign Setup story importing it from v4.
- **The reference components are close in different ways.** Charcoal-header examples match the requested color direction; the 102326 campaign and asset tables match column content, status cells and controls. Their exact columns, typography, sorting behavior and actions differ from v4.
- **A full visual match needs more than the header fill.** Compare label size/weight, white text, sort icons, borders, row density, numeric alignment, totals, empty states, selections and action cells. V4 holds text to its own 15px minimum, while several reference tables use smaller labels.
- **Full performance is configurable.** `view-d` starts with Creative; `view-d-pivot` uses Creative × Platform; `view-d-keywords` shows per-keyword rows. The stories here select Table view to keep the results visible.
- **Bulk-selection columns are conditional.** Asset and keyword libraries expose them in selection mode. The selected-items table instead has remove buttons and a dashed empty state.
