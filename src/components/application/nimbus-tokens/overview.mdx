# Nimbus tokens

From the 26 Oct review of Round 4: the DAS functionality and information design are
approved, and what's left is making sure “the rules of how this gets outputted visually
are in place.” Once DAS matches Performance Insights, **one rule change fixes everything**
— and the Performance Insights redesign that comes next doesn't start from scratch.

Every token lives once, in `prototypes/das/v5/screens/nimbus-ui.tsx`. Prototype v5 draws
its screens from it, and these stories show the same exports.

## Still open

## The 15px floor

V5 holds text to the 15px minimum (Audits › Typography Rules), so labels — date labels,
table headers — read larger than staging's 10–13px. Colour, weight, rules, fills and
stripes follow staging.
