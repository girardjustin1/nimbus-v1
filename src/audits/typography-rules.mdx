## 1. The three rules

1. **Headlines are extra bold (800).** Page titles, section headlines, and rail and modal titles.
2. **Labels are bold (700) and black.** Field labels, radio and checkbox options, and the titles of targeting cards (those use 700, not 800).
3. **Nothing is smaller than 15px.** Not hints, badges, table cells, buttons, uppercase text, or chart axes. The exceptions are in section 5.

## 2. The scale

<MdTable md={`
| Size | Line height | Tailwind | Used for |
|---|---|---|---|
| **26px** | 30px | \`text-xl\` | Section headlines |
| **24px** | 32px | \`text-display-xs\` | Page titles (800), KPI numbers (600) |
| **18px** | 28px | \`text-lg\` | Panel titles (800), card titles (700) |
| **15px** | 24px | \`text-md\` | Everything else: labels, body, buttons, tables, badges, errors |
`} />

<MdTable md={`
| Weight | Tailwind | Used for |
|---|---|---|
| **800** | \`font-extrabold\` | Headlines only |
| **700** | \`font-bold\` | Labels, card titles, required marks, badges |
| **600** | \`font-semibold\` | Buttons, text actions, column headers, eyebrows, statuses, nav, KPI numbers |
| **500** | \`font-medium\` | Values, errors, placeholders |
| **400** | (default) | Body text and table cells |
`} />

**Font:** Proxima Nova (Adobe Fonts kit, 300–900), with the system monospace stack for data. `text-xs` (12px) and
`text-sm` (13px) are not used anywhere in Prototype 3.

## 6. In the code

Everything lives in `prototypes/das/v3/screens/type-rules.tsx`:

<MdTable md={`
| Export | What it does |
|---|---|
| \`HEADLINE\` | \`font-extrabold\` — put it on every headline |
| \`LABEL\` | \`text-md font-bold text-primary\` — option labels, Start / End, anything that is a label but not a design-system Label |
| \`FIELD_TYPE\` | Applied once on the page shell. Restyles every design-system Label (\`[data-label]\`) to LABEL and every hint / error (\`[slot=description]\`, \`[slot=errorMessage]\`) to 15px |
| \`Button\` | The design-system Button with \`text-md\` (its own sizes are 13px) |
| \`AdFormatDemo\` | The Studio ad preview with its caption and Pause / Replay at 15px |
`} />

**Checklist for a new v3 screen**

- Render inside `DasShell`. It applies `FIELD_TYPE` and the nav-footer fix.
- Import `Button` from `./type-rules`, not from the design system.
- Use `text-md` for all body text. Never `text-xs`, `text-sm` or `text-[Npx]` under 15.
- Use `size="md"` on Input, RadioGroup and Checkbox (when it has a label).
- Use `HEADLINE` on headlines and `LABEL` on custom labels.
- Popovers portal outside the shell, so set `**:text-md` on their panel.

**Enforced in CI:** `prototypes/das/v3/screens/type-rules.test.ts` fails if any v3 screen uses `text-xs`, `text-sm`, a
pixel size under 15, or an Input at `size="sm"`.
