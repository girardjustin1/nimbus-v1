# DAS Studio: build with the result in view

<div style={{ background: "#F9FAFB", border: "1px solid #EAECF0", borderRadius: 14, padding: "16px 20px", margin: "8px 0 24px", fontSize: 15, lineHeight: 1.65, color: "#344054" }}>
  <strong>The experience.</strong> A publisher builds a deal campaign in a focused, full-screen studio: pick a goal from four
  visual tiles, name the deal, choose who sees it, then set budget, bid and dates. A live panel estimates delivery likelihood,
  impressions and reach as they go, and the bid shows where it sits in the recommended range. While building the creative,
  the ad renders in a real app screen beside the form and updates with every keystroke. Review leads with the flight, budget
  and a render of the ad, and a full-screen preview steps through every moment of the format before anything is published.
</div>
