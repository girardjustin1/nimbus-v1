# Engineering constraints

What engineering shared for this rebuild: which parts of the dashboard are hard to restyle,
which components the dashboard uses most, and which styles carry the most weight. These
decide how far each page in this category moves from staging.

## Styles that carry the most weight

1. **Global styles** — font, greys, containers, buttons, type and layout utilities, tabs, links: every page.
2. **Form fields** — create and edit forms across the app.
3. **Tables** — the manage lists.
4. **Modals** — confirms, errors, prompts.
5. **Sticky bars** — the report and dashboard filter headers.
6. **Dropdown presets** — most selects.
7. **Brand accents** — pink, teal and the border greys.
8. **DAS styles** — the Deal Activation System only.
9. **Area styles** — reports, dashboard, demand, floors, profile: each owns its section.
10. **Charts, date picker, payments, promos** — narrow or third-party; lowest priority.

There is no real token system in production today: colours and type are hard-coded
across stylesheets and script style objects. The Nimbus tokens in this Storybook are what
replaces them.
