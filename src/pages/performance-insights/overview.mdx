# Performance Insights — redesign concepts

<div style={{ background: "#F9FAFB", border: "1px solid #EAECF0", borderRadius: 14, padding: "16px 20px", margin: "8px 0 24px", fontSize: 15, lineHeight: 1.65, color: "#344054" }}>
  <strong>The experience.</strong> A publisher opens Performance Insights and starts from a template or saved query instead of a
  blank wall of checkboxes. They build a question as one readable sentence ("show revenue and eCPM by demand source for the
  last 7 days…") that only runs when they ask, see every number next to its change from the previous period, and drill from
  app to demand source in a pivot view. It's fast, easier to read, and ready for the DAS and keyword dimensions coming next.
</div>

Today's Performance Insights shows every metric and breakdown as an always-visible checkbox,
loads data up front, and can't absorb new dimensions: DAS already added three, and keyword
targeting would add an unbounded number. These concepts explore replacements. They use the
Nimbus design system and fictional sample data.
