# Charts

Every chart type from Untitled UI, plus five that reporting needs, restyled as one Nimbus
family. They're built on **Recharts** (the library Untitled UI uses) with shared Nimbus
chrome: the card, legend, change badge and dark tooltip. See them all together in the
<S id="gallery--dashboard">Gallery</S>.

The vendored versions under **Application UI › Charts** are left as-is, so syncing Untitled
UI never overwrites these.

## Style

- **Palette, in order:** <Swatch c="#DA6EA3" n="Pink" /><Swatch c="#37B6B7" n="Teal" /><Swatch c="#6172F3" n="Indigo" /><Swatch c="#F79009" n="Orange" /><Swatch c="#A94579" n="Deep pink" /><Swatch c="#1F7F80" n="Deep teal" /><Swatch c="#98A2B3" n="Gray" />
- **Comparisons** (previous period) are gray and dashed.
- **Axes** have no lines or ticks, and gridlines are horizontal and dashed.
- **Lines** are 2.5px, smooth, with no dots until hovered. **Areas** fade from 30% to clear. **Bars** have 6px rounded ends.
- **Tooltips** are dark cards with a colour dot per series, and every value is formatted (`$`, `%`, `K`/`M`).
- **Good vs bad change** is teal vs pink. It can be flipped when a fall is good, e.g. timeout rate.

## Using them

```tsx
import { NimbusLineChart } from "@/pages/performance-insights/charts/cartesian-charts";
import { ChartCard, Legend } from "@/pages/performance-insights/charts/chart-kit";

<ChartCard title="Revenue" value="$55,330" change={0.023} legend={<Legend items={…} />}>
    <NimbusLineChart data={rows} xKey="day" fmt="usd" series={[{ key: "This week" }, { key: "Previous week", dashed: true, color: "#98A2B3" }]} />
</ChartCard>
```

All sample data is fictional. These live in Storybook for now. Once approved, they can move
into **Application UI** and power the Performance Insights prototype.
