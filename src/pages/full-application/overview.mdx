## Brand and tokens

The theme comes from the Nimbus design tokens and lives in `src/styles/theme.css`:

- **Brand** — pink primary (`#DA6EA3`) with teal (`#37B6B7`) as the secondary accent.
- **Neutrals** — a warm grey scale for surfaces, text and borders.
- **Typography** — Proxima Nova; body text at 15px (`text-md`), nothing smaller in product UI.
- **Radius and spacing** — Nimbus token values (e.g. `radius-md` 8px).

Reuse the theme classes (`bg-brand-solid`, `text-primary`, `border-secondary`, `text-md`) and new work inherits
the brand.

## Getting started

```bash
npm install              # install dependencies
npm run storybook        # this library at http://localhost:6006
npm run proto:dev        # the prototypes at http://localhost:5190 (/app/ is the full application)
npm run build-storybook  # static build → ./storybook-static
```

Built with React 19 · TypeScript · Tailwind CSS v4 · React Aria · Recharts · Storybook 10 · Vite. Hosted on
[GitHub Pages](https://girardjustin1.github.io/nimbus-v1/) (primary) and [Netlify](https://nimbus-ds-v1.netlify.app/)
(backup); both deploy from `main`.
